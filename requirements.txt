# NOTE ON DLIB / face_recognition
# --------------------------------
# `face_recognition` depends on `dlib`, which compiles from C++ source.
# Before running `pip install -r requirements.txt` you need:
#
#   Windows:
#     - Install Visual Studio Build Tools (C++ workload) from:
#       https://visualstudio.microsoft.com/visual-cpp-build-tools/
#     - Install CMake: https://cmake.org/download/
#       (add to PATH during install)
#     - OR use a pre-built wheel (easier):
#       https://github.com/z-mahmud22/Dlib_Windows_Python3.x
#       Download the .whl for your Python version and run:
#         pip install dlib‑19.24.0‑cp311‑cp311‑win_amd64.whl
#
#   macOS:
#     - brew install cmake dlib
#
#   Linux (Ubuntu/Debian):
#     - sudo apt-get install cmake build-essential libopenblas-dev liblapack-dev
#
# After dlib is installed, `pip install face_recognition` will work.
# ============================================================================
